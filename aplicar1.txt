ANÁLISE E REFATORAÇÃO COMPLETA DO PROJETO

Repositório:

https://github.com/FabioSilva11/PDV2.0.git

OBJETIVO GERAL

Refatorar o PDV para que ele seja:

- de um único estabelecimento;
- com um único administrador principal;
- com usuários operacionais adicionais;
- sem Firebase;
- sem sincronização Firebase;
- sem dependência de Realtime Database;
- com MariaDB como única fonte persistente de dados;
- com localStorage apenas como cache/fallback temporário do frontend quando o MariaDB estiver indisponível;
- com toda a configuração do estabelecimento armazenada no MariaDB;
- sem dados de negócio importantes hardcoded no código;
- sem dados empresariais fictícios;
- sem métricas de operação fictícias;
- sem IPs de impressoras fictícios como configuração real;
- sem usuário administrador fixo no código.

IMPORTANTE:

Não fazer uma simples substituição de:

Firebase → MariaDB

Mantendo o restante da arquitetura inconsistente.

Reestruturar as fontes de verdade para que:

BANCO MARIA DB
↓
API BACKEND
↓
FRONTEND / APP GARÇOM
↓
CACHE LOCAL OPCIONAL

O MariaDB é a autoridade.

localStorage NÃO é a fonte definitiva.

Firebase deve ser completamente removido.
